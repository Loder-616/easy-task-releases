# Easy Task

Easy Task は、Android・iPad・Macでタスクや予定を管理するためのアプリです。

現在はテスト版として、家族や身近な人に使用してもらいながら改善しています。

## Android版

最新版は GitHub Releases からダウンロードできます。

https://github.com/Loder-616/easy-task-releases/releases/latest

過去のバージョンも Releases に残しています。

## iPad / iPhone版

TestFlightで配布予定です。

TestFlightリンク：準備中

## macOS版

配布準備中です。

## 主な機能

- タスク・予定管理
- カレンダー表示
- Firebaseによる端末間同期
- 優先度設定
- 完了・未完了管理
- 期限前通知
- 期限通知
- 期限切れ通知
- Android / iPad ウィジェット
- 高優先度タスクの強調表示
- Galaxyアラーム風の時刻選択UI
